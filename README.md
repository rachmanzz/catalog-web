# 🛍️ IDKATALOG  
Website E-Katalog Sederhana & Open Source

![IDKATALOG Banner](https://via.placeholder.com/1200x400?text=IDKATALOG+-+Simple+E-Catalog)

**IDKATALOG** adalah website **e-katalog open source** yang membantu pelaku usaha menampilkan produk secara online dengan cara **praktis, ringan, dan mudah digunakan**.

Cocok untuk:
- 🍰 Kue & makanan rumahan  
- 🧶 Kerajinan tangan  
- 🛒 Produk UMKM  
- 📦 Produk custom & pre-order  

Pembeli dapat melihat katalog dan langsung **melakukan pemesanan via WhatsApp** hanya dengan satu klik.

---

## ✨ Fitur Utama
- 📋 Tampilan katalog produk yang sederhana & rapi
- 🖼️ Upload foto produk
- 📝 Keterangan & deskripsi produk
- 💬 Tombol **Order via WhatsApp**
- 📱 Responsive (mobile friendly)
- ⚡ Ringan & cepat diakses
- 🔓 Open Source

---

## 🔐 Halaman Admin
IDKATALOG dilengkapi **halaman admin** untuk mengelola katalog:

### Fitur Admin
- 📤 Upload foto katalog
- ✏️ Tambah & edit keterangan produk
- 🗂️ Kelola daftar produk dengan mudah

### Catatan Penting Gambar ⚠️
- 📏 **Ukuran gambar disarankan:**  
  **300×300 px** atau **400×400 px**
- 🚫 **Tidak ada auto-crop**
- 🚫 **Tidak ada optimasi gambar otomatis**
- 📉 Gambar terlalu besar dapat membuat website menjadi **berat & lambat**

> ⚠️ Disarankan melakukan resize & kompres gambar sebelum upload.
